# 공 단계별 외형 컨셉 (이미지 생성 전 기획안)

상태: **초안 — 사용자 확인 전. 이 문서가 확정되기 전에는 이미지를 생성하지 않는다.**
방향 (사용자 지시, 2026-10-30): 5단계마다 컨셉이 있고, 공 본체 디자인 자체가 드라마틱하게 바뀐다. 변하는 모습을 보고 싶어서 더 플레이하게 만드는 것이 목표다.
기존 GDD 6.4의 "기본 디자인 위에 장식을 겹친다"는 이 방향과 다르다. 이 문서가 확정되면 GDD 6.4와 9장을 먼저 고친다.

## 1. 구간 규칙 (모든 종류 공통)

이름 사다리가 단계마다 바뀌듯, 외형은 5단계 구간마다 바뀐다 (+5~9는 +5 외형, +10~14는 +10 외형 …). 구간 외형은 그 구간 첫 단계 이름이 말하는 이미지를 그대로 그린다.

컨셉을 정하는 공식은 하나다: **컨셉 = (그 구간 첫 이름이 말하는 핵심 이미지) × (구간 규칙)**.

| 구간 | 한 줄 정의 | 본체 | 실루엣 | 화려함 (1~10) | 공의 본질 |
|---|---|---|---|---|---|
| **+0** | 기본 | 확정된 현재 이미지 그대로 | 원형 | 1 | 완전 유지 |
| **+5** | 기본에서 **약간 변형** | 같은 공인데 "방금 달라진 순간". 재질의 상태가 한 가지 바뀌고(열기, 윤기, 점등 등) 디테일 1~2개 추가. 채도 한 단계 상승 | 원형 그대로 | 2~3 | 완전 유지 |
| **+10** | **확실히 멋있다** | 본체를 재설계한다. 종류의 상징 모티브 1개가 본체에 박혀 눈에 띄게 등장하고 패턴이 새로 바뀐다. 발광 포인트와 색 대비가 뚜렷하다 | 원형 + 작은 돌출 · 고리 1~2개 | 6 | 유지 |
| **+15** | +10과 같은 계열이지만 **더 화려** | +10 디자인의 진화형. 같은 모티브가 커지고 복잡해진다. 공 주위에 분리된 부품(궤도 파편 · 위성 · 고리)이 2~4개 떠돈다 | 원형 + 공 주위에 떠도는 것들 (유체·현상형은 형태가 흐르거나 흩어져도 됨) | 7.5 | 고체형은 유지, 유체·현상형은 흐려져도 됨 |
| **+20** | **대놓고 과하다** | 신화적 장식이 본체와 한 몸이 된다 (날개 · 왕관 · 갑옷). 공은 "신의 구체"로 변이한다 | 공 지름의 약 2배로 확 커진 실루엣 | 9.5 | 희미해지기 시작 |
| **+25** | +20의 극대, **현상이 된 공** | 공 자체가 하나의 현상 (폭풍 · 은하 · 시간 정지 · 행성). 화면 환경까지 바뀐다 | 화면의 절반 | 10 | 거의 잊힘 |
| **+30** | **궁극 완전체** | 종류의 개념이 곧 공이다. 화면 전체를 장악한다 | 화면 전체 | 10+ | 잊힘 |

공통 규칙:
- **이전 구간과 같은 팔레트 계열을 유지**한다. 같은 공이 자라는 것으로 보여야 하지 이어 붙인 다른 공으로 보이면 안 된다. 색은 구간이 오를수록 채도와 대비가 올라간다.
- **+10부터 새 모티브**가 등장하고, +15는 그 모티브를 키운다. +20에서 다음 모티브(신화적 장식)가 열린다.
- **공 본질이 흐려져도 되는 시점은 종류의 성질에 따른다** (사용자 지시, 2026-10-30: "용암처럼 흐르는 성질이나 흩어지는 성질이 있는 경우 15강부터 흐려져도 된다"). 아래 "성질 분류"를 따른다.
- **도감에서 이미지를 볼 수 있어야 한다** (사용자 지시). 그래서 모든 구간 이미지는 (1) 배경이 투명한 독립 이미지여야 하고 (2) 도감 썸네일 크기(약 40px)에서도 종류와 단계 구간이 구분되어야 하며 (3) 효과만 따로 겹치는 방식이 아니라 그 자체로 한 장의 완성된 공 그림이어야 한다. 도감은 종류별 대표 이미지와 단계별(구간 이미지) 썸네일을 보여 준다. 아직 만나지 못한 종류는 실루엣으로만 보인다.
- 이미지에 **글자 · 숫자를 넣지 않는다.** 실존 선수 · 구단 · 로고도 넣지 않는다 (명장면 공은 사건의 "상징물"만 그린다).
- 구간 사이의 점프가 눈에 띄어야 한다. 특히 +5 → +10 은 "어, 변했다", +10 → +15 는 "더 커졌다", +15 → +20 은 "미쳤다"여야 한다.

### 성질 분류 (공 본질이 흐려져도 되는 시점)

| 분류 | 종류 | 공 형태를 유지하는 한계 |
|---|---|---|
| **고체형** — 단단한 물체라 형태를 유지한다 | 동네 축구공, 고무공, 비닐 뭉치공, 헌 가죽공, 명장면 공, 구리 공, 황금공, 수정공, 유리공, 네온 사이버공 | **+15까지 공**, +20부터 변이 |
| **유체·현상형** — 흐르거나 흩어지는 성질이 있다 | 용암공, 불꽃공, 번개공, 오로라 공, 블랙홀 공, 우주공, 야광공, 무지개 공, 은하 심장 공, 시간의 공(모래), 얼음공(서리·눈보라로 흩어짐), 스펀지 공(물이 쏟아짐) | **+10까지 공**, **+15부터 형태가 흐르거나 흩어져도 됨**. 예: 용암공 +15 는 공 아래로 용암이 흘러내려 실루엣이 길어지고, 번개공 +15 는 번개가 공을 감싸 윤곽이 번개로 흩어짐 |

분류는 제안이다. 종류를 옮기고 싶으면 알려 달라.

구간 이름 매핑 (이름 사다리의 어느 이름을 컨셉 근거로 쓰는가): +5 → +5번째 이름, +10 → +10번째 이름, … 컨셉 표에 각 구간의 근거 이름을 함께 적었다.

## 2. 종류별 컨셉 (22종 × 6구간)

각 종류는 한 줄 진화 요약 + 구간 표다. "+0" 줄은 이미 확정된 이미지이고, 나머지가 새로 만들 이미지다. **+20 이상은 크레딧이 생기면 만든다** (컨셉은 지금 정해 둔다).

### 일반

#### 동네 축구공 (common_0)
진화: 흙먼지 낡은 가죽공 → 대장이 아끼는 공 → 금박 골목대장 공 → 별이 박힌 우주 축구공 → 신구 → 평행우주 → 은하를 담은 대축구공

| 구간 | 근거 이름 | 외형 컨셉 |
|---|---|---|
| +0 | 바람 빠진 동네 축구공 | (확정) 흙먼지 묻은 낡은 흑백 가죽 축구공 |
| +5 | 동네 대장이 아끼는 가죽공 | 같은 축구공을 닦아서 가죽에 윤이 나고 흙 얼룩이 사라짐. 한 패널에 금실 스티치 한 줄, 작은 가죽 이름표가 달림 |
| +10 | 전설의 골목대장 공 | 패널 테두리가 금박으로 재설계된 클래식 공. 표면에 별과 불꽃 낙서 문양, 승리 리본이 공을 한 바퀴 휘감음 |
| +15 | 만물의 근원 우주의 축구공 | 패널 안쪽이 별이 박힌 밤하늘 무늬로 바뀌고 오각형마다 작은 행성. 위성 3개와 궤도 고리가 공 주위를 돎 |
| +20 | 우주 대회를 제패한 축구의 신구 | 황금과 성운의 갑옷 공. 뒤에 월계수 날개 한 쌍, 트로피 모양 왕관, 경기장 조명 같은 광륜 |
| +25 | 모든 평행우주의 승리를 모은 공 | 같은 공의 잔상 수십 개가 방사형으로 겹침. 잔상마다 다른 색의 우승 트로피 실루엣 |
| +30 | 무한우주를 골로 끝내는 종언의 대축구공 | 은하 전체를 담은 거대한 금빛 구. 골대 모양 성운의 문, 화면을 가르는 마지막 슛의 궤적 |

#### 고무공 (common_1)
진화: 빨간 고무공 → 탄력 붙음 → 끝없이 튀는 공 → 우주를 튕기는 젤리 공 → 고무의 신 → 반동의 시작과 끝 → 우주를 되감는 고무구

| 구간 | 근거 이름 | 외형 컨셉 |
|---|---|---|
| +0 | 말랑하게 늘어진 고무공 | (확정) 광택 한 줄 있는 단순한 빨간 고무공 |
| +5 | 점점 탄력이 붙는 고무공 | 바닥에 닿아 살짝 눌렸다 펴지는 순간의 납작한 모습. 광택이 길게 늘어나고 작은 먼지 구름이 한 점 |
| +10 | 끝없이 튀어 오르는 탄성의 공 | 공 속에 용수철 코일 무늬가 비치고 표면에 별 모양 반동 문양. 뒤로 튕긴 궤적의 잔상 아치 3개 |
| +15 | 우주를 탄성으로 튕기는 공 | 고무가 반투명 분홍-보라 젤리로 변하고 표면에서 작은 행성들이 튕겨 오름. 탄성 파동 고리가 퍼짐 |
| +20 | 우주 탄성의 근원 고무의 신구 | 용수철 모양 날개 한 쌍, 점프하는 스프링 광륜 왕관, 표면에 고무 신의 눈 문양 |
| +25 | 모든 반동의 시작과 끝을 쥔 공 | 튕길 때마다 생긴 파문이 행성 궤도처럼 층층이 겹침. 자기 자신을 튕겨 내는 분신 공 |
| +30 | 무한 반동으로 우주를 되감는 종언의 대고무공 | 한 번의 튕김에 화면이 압축과 팽창을 반복하는 거대 고무 구. 충격파 고리가 화면 끝까지 |

#### 비닐 뭉치공 (common_2)
진화: 테이프로 감은 비닐 뭉치 → 압축된 비닐 → 천 겹 갑옷 → 별빛 끈 구 → 재활용의 신 → 뫼비우스 매듭 → 영원을 봉한 대매듭

| 구간 | 근거 이름 | 외형 컨셉 |
|---|---|---|
| +0 | 테이프로 겨우 감아 놓은 비닐 뭉치 | (확정) 구겨진 비닐봉지를 베이지 테이프로 감은 뭉치 |
| +5 | 점점 단단하게 뭉쳐지는 비닐공 | 비닐이 압축돼 매끈한 반투명 구에 가까워지고 테이프가 정돈된 십자로 감김. 반짝임 점 |
| +10 | 천 겹으로 뭉친 불굴의 비닐공 | 겹겹의 층이 단면처럼 보이는 다층 구. 갑옷 벨트 같은 테이프, 층 사이로 무지갯빛 기름막 반사 |
| +15 | 우주의 끈으로 감아 만든 공 | 비닐 가닥이 별빛 실로 변해 궤도처럼 칭칭 감김. 성운 색, 끈 끝에 작은 별이 매달림 |
| +20 | 우주 재활용의 신구 | 버려진 행성 조각(캔 · 병 · 타이어)이 엮인 재활용 신. 비닐 날개, 순환 화살표 광륜 (일반 형태, 상표 아님) |
| +25 | 모든 끝과 끝을 이어 붙인 공 | 끝없이 이어진 하나의 끈이 뫼비우스처럼 공을 감쌈. 끊어진 세계 조각들이 매듭으로 이어짐 |
| +30 | 무한을 칭칭 감아 영원을 봉하는 종언의 대뭉치공 | 은하 규모의 거대 매듭 구. 영원을 봉하는 문양, 화면을 끈으로 가둠 |

#### 헌 가죽공 (common_3)
진화: 꿰맨 자국투성이 → 윤이 도는 가죽 → 흉터 위의 갑옷 → 별자리 우주 소가죽 → 신이 꿰맨 구 → 영웅들의 환영 → 승부의 기억 대구

| 구간 | 근거 이름 | 외형 컨셉 |
|---|---|---|
| +0 | 꿰맨 자국투성이 헌 가죽공 | (확정) 갈라지고 꿰맨 두꺼운 스티치의 낡은 갈색 가죽 |
| +5 | 세월의 광이 도는 가죽공 | 기름을 먹어 짙은 윤이 나고, 스티치가 금실로 보강됨. 낡았지만 단단한 인상 |
| +10 | 만 번 맞고도 터지지 않은 불굴의 공 | 흉터마다 금속 리벳과 가죽 갑옷 패치가 붙음. 흉터 사이로 붉은 불굴의 기운, 벨트 버클 |
| +15 | 우주 소가 남긴 불멸의 가죽공 | 별무늬 우주 소가죽. 별자리가 흉터를 이어 그려지고 뿔 모양 장식 두 개 |
| +20 | 가죽의 신이 마지막으로 꿰맨 신구 | 신의 황금 실로 짠 거대 가죽 구. 바늘 모양 날개, 흉터가 룬 문자처럼 빛남 |
| +25 | 모든 은퇴한 영웅이 돌아온 공 | 가죽 위에 영웅들의 익명 실루엣 수십 명이 새겨져 빛나고 환영이 공을 둘러쌈 |
| +30 | 모든 승부의 기억을 꿰매어 완성한 종언의 대가죽공 | 모든 시합 장면이 가죽 패치로 이어진 거대 구. 황금 스티치가 은하처럼 번짐 |

### 고급

#### 명장면 공 (uncommon_0) — 실제 대회의 유명한 골이 모티브
이 종류의 이름은 실제 사건이다. 이미지는 **사건의 상징물만** 그린다 (익명 실루엣, 얼굴 · 번호 · 유니폼 디자인 · 국기 · 로고 없음). 근거: `docs/REAL_GOALS_FACTS.md`.
진화: 흰 육각 패턴 공 → 패스 궤적이 새겨진 공 → 날아다니는 헤딩의 속도선 → 연장전의 붉은 함성 → 크로스바에 걸린 공 → 승부차기 스포트라이트 → 60야드 질주의 월계관

| 구간 | 근거 이름 | 외형 컨셉 |
|---|---|---|
| +0 | 1930년 대회 사상 첫 골이 터진 낡은 공 | (확정) 흰색 육각 패턴의 단정한 공 |

## 3. 제작 방식 (아직 실행하지 않음)

1. **시안 먼저, 한 종류로 시험**: 용암공 시트 1장(약 60~70원)으로 +5 · +10 · +15 가 의도한 드라마인지 확인하고 방향을 확정한다. 이 문서의 구간 규칙과 용암공 컨셉이 기준이다.
2. 종류별 **시트 1장 (2×2, 512)**: 칸은 +5 / +10 / +15 와 크기 기준용 +0 재현칸이다. 확정된 +0 이미지를 참고 이미지로 주고 "같은 공이 이렇게 변한다"로 그린다. 공 본체 지름은 칸 폭의 약 55%로 고정한다.
3. 후처리: 마젠타 배경 제거 → 공 본체가 +0과 같은 도트 밀도가 되게 줄임(칸 128px, 본체 약 64~70px) → 팔레트 제한. 각 칸 가장자리는 검게 지워 칸 테두리 선을 없앤다. 효과가 번지는 부분은 "단단한 픽셀 띠로 그려라"로 분홍 번짐을 막는다.
4. 게임: 단계 구간에 맞는 이미지로 **공 이미지 자체를 교체**한다 (+5~9 → +5 이미지). 구간이 바뀔 때 이름과 함께 "변신" 연출이 터진다.
5. GDD 9장대로 **등급 묶음(6개)마다 확정**한다. 확정 전에는 게임에 넣지 않는다.
6. **GDD 6.4와 9장은 이 컨셉이 확정되면 먼저 고친다.**

예상 비용 (장당 512 시트 55~75원, 재시도 ×1.5): +5 · +10 · +15 전체는 22장 + 재시도 약 33장, **약 1,800~2,500원**. +20 · +25 · +30 은 같은 방식으로 한 번 더 약 1,800~2,500원 (+20 이상은 나중으로 유지).

## 4. 확인이 필요한 것
1. 구간 규칙 표(특히 +5는 "약간 변형", +10은 "확실히 멋있다", +15는 "+10의 더 화려한 버전")가 의도와 맞나요?
2. 성질 분류(고체형은 +15까지 공, 유체·현상형은 +15부터 흐려져도 됨)에서 종류를 옮기고 싶은 것이 있나요?
3. 종류별 컨셉 중 마음에 안 드는 것이 있으면 종류 이름과 구간만 알려 주세요.
